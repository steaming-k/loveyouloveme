## 5. 수정하지 않은 것

### POLISH-01 — 다가가는 힌트 카테고리 라벨 중복

`APPROACH_HINT_KIND_LABEL`에서 `pace`와 `affection`이 같은 문자열(`관계 속도를 맞출 때 참고할 것`)을
쓴다. 두 힌트가 함께 뜨면 같은 제목이 연속으로 두 번 보인다(카드 내용은 다름).
→ 신뢰·흐름·state·상품구조·meta 어디에도 해당하지 않는다. **H10 결과를 보고 판단한다.**

### POLISH-02 — `/ut` 콘솔의 `AI 모드` 표시가 서버 모드와 어긋남

콘솔은 `NEXT_PUBLIC_AI_MODE`만 읽는다(`AI_MODE_HINT`). 지금처럼 `AI_MODE=demo` ·
`NEXT_PUBLIC_AI_MODE=real`이면 콘솔은 `real`이라고 표시하지만 서버는 demo다.
참가자 화면 문제가 아니라 **운영자 도구 표시** 문제라 RC 범위 밖으로 둔다.
→ 대신 pre-flight 절차에서 `/api/dev/ai-guard`로 **서버 값**을 확인하도록 했다(§6).

### HYPOTHESIS — Premium 리포트 도달 조건 (⚠️ UT 운영 필수)

`hasPremiumEvidence`는 두 경로 중 하나를 요구한다:
1. cross-source insight 1개 이상 (서로 다른 source ≥2 · evidenceRef ≥2 · 무료와 중복 아님)
2. `mirror.insights.length === 0` **이고** declared 축 충분

**사진 없이** 완주한 세션(declared 4 + 관계경험 3 + 상대 4/4 + 심화입력 2 + 사건 1 +
MBTI 양쪽 + 생년월일 양쪽)에서 두 경로 모두 불충족 → Premium은 리포트 대신
`정밀 분석을 위해 몇 가지 정보가 더 필요해` 보완 화면을 연다(가격 0 · 탈출구 있음).
사진 관찰이 있는 세션에서는 리포트가 정상적으로 열린다(검증함).

이건 **제품 결함이 아니라 의도된 계약**이다(v1.26 "없는 것을 팔지 않는다").
근거 게이트를 낮추는 것은 신뢰 계약을 깨는 일이라 **하지 않는다.**

⚠️ 그러나 1차 UT 참가자 2명 모두 테스트 기기에 사진이 없었다
("내 컴퓨터에는 사진이 하나도 없는데"). 사진 없이 진행하면
**H5 · H6 · H7 · H8을 한 명도 관측할 수 없다.** → §6 pre-flight에 필수 항목으로 넣었다.

### 이번에 손대지 않기로 한 것

```

   → lym.* 저장값 삭제 + /onboarding으로 이동 (검증함)

   - Premium CTA · Paywall 노출 ✓
   - 실제 결제 불가 ✓
   - 참가자 화면에 개발 도구 없음 ✓   (preview 배포는 NEXT_PUBLIC_AI_DEBUG=false)
5. 서버 AI 모드는 콘솔이 아니라 /api/dev/ai-guard 로 확인 (POLISH-02)
   → {"realProviderCalls":0,"envMode":"demo"}
```
