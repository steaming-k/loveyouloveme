# 2차 UT 검증 가설 (260915)

> 1차 UT에서 나온 문제는 수정했다. 그러므로 2차 UT에서 볼 것은
> **"수정이 실제 행동을 바꿨는가?"** 하나다.
>
> 1차에서 이미 답을 얻은 질문을 반복하지 않는다.
> 새 아이디어가 나와도 이번 UT 중에는 구현하지 않는다 — 기록만 한다.

## 진행 원칙

```
과업은 준다. 위치는 알려주지 않는다.
사용자가 막히면 어디서 막혔는지가 데이터다 — 즉시 구조하지 않는다.
유도 질문 금지. 기능을 먼저 설명하지 않는다.
사용자 언어를 그대로 받아적는다. 요약하지 않는다.
```

⚠️ **사진은 준비시키지 않는다.** 사진은 optional 입력이고, 사진 없이도 Premium 리포트가
열린다(BLOCKER-02 수정). 1차 참가자 2명 모두 기기에 사진이 없었으므로 **사진 없는 흐름이
오히려 기본 경로에 가깝다** — 그대로 진행한다. H3(Photo trust)를 관측하고 싶은 참가자에게만
권장 수준으로 안내하고, 사진 유무를 기록해 H5~H8 응답과 함께 본다.

---

## H1. 질문 깊이 — Optional Deep Input

**변경한 것**: 필수 질문을 늘리는 대신, 관계 경험 3/3에 `+ 더 자세히 알려주기 (선택)`를
두고 사용자가 중요하다고 답한 축에서 최대 2문항을 더 묻는다. 점수에는 반영하지 않는다.

**1차 신호**: "질문이 너무 얕았음. 이걸로 뭘 알겠어?" / "세부 질문이 부족했던 것 같다"

| | |
|---|---|
| 가설 | 필수 질문을 늘리지 않아도, 원하는 사람이 스스로 더 답할 수 있으면 '얕다'는 반응이 준다 |
| 관찰할 행동 | 버튼을 **스스로** 여는가 · 몇 초 망설이는가 · 2문항을 다 답하는가 · 중간에 `이만 됐어`로 나가는가 |
| 질문 | (열었으면) "여기서 뭘 더 물어볼 거라고 생각하고 누르셨어요?" · (안 열었으면) "이 버튼은 뭐라고 생각하셨어요?" · "답하고 나서 결과가 달라졌다고 느끼셨어요?" |
| 성공 신호 | 스스로 연다 · "내 얘기 같다"는 반응이 A/B로 갈린다 · '얕다' 언급 감소 |
| 실패 신호 | 버튼을 못 본다 · "굳이?" · 열었지만 무엇을 묻는지 몰라 닫는다 |

⚠️ `질문이 많아요/적어요`로 묻지 않는다. 양이 아니라 **깊이와 자발성**을 본다.

## H2. 분석 근거 충분성

**1차 신호**: "이걸로 뭘 알겠어 하는 느낌" / "이미 알고 있는 내용이 너무 많아"

| | |
|---|---|
| 가설 | 근거를 입력값과 이어서 보여주면(`이렇게 생각한 이유 01 · 02`), 입력량이 적어도 납득된다 |
| 관찰할 행동 | `이 점수는 어떻게 나왔어?` · `왜 이렇게 봤어?` · `근거`를 펼치는가 · 펼친 뒤 읽는가 |
| 질문 | "이 정도 입력으로 이런 결과가 나온 게 납득이 되셨어요?" · "어디를 보고 그렇게 느끼셨어요?" |
| 성공 신호 | 근거를 펼쳐보고 "아 이걸 보고 그런 거구나" · '이걸로 뭘 알아' 감소 |
| 실패 신호 | 근거를 안 펼친다 · 펼쳐도 "당연한 말" · "내가 쓴 걸 그대로 말해주네" |

## H3. Photo trust

**변경한 것**: 사진 관찰을 확정 사실로 쓰지 않고 확인/수정/거절을 받는다. 거절한 관찰은
downstream(궁합·Mirror·Premium·History·Lens) 어디에도 가지 않는다.

**1차 신호**: "고양이 인형이 아님. 인형이 왜 '반려동물과 함께'에 포함되는 거임?"

| | |
|---|---|
| 가설 | 틀린 관찰을 쉽게 거절할 수 있고 결과에서도 사라지면, 한 번 틀려도 신뢰가 깨지지 않는다 |
| 관찰할 행동 | 틀린 항목을 발견하는가 · 거절/수정 컨트롤을 찾는가 · 거절 후 결과를 다시 확인하는가 |
| 질문 | "이 관찰 중에 틀린 게 있었나요?" · "틀린 걸 어떻게 하면 될 것 같으세요?" · (거절 후) "지금 결과에 그 내용이 남아 있나요?" |
| 성공 신호 | 스스로 거절/수정 · "빠졌네요" 확인 · 틀린 뒤에도 나머지를 신뢰 |
| 실패 신호 | 거절 방법을 못 찾음 · 거절했는데 남아 있다고 느낌 · 하나 틀리자 전체를 불신 |

---

## H4. Navigation

**변경한 것**: 결과 화면에 하단 Nav 상시 · Back은 진입 경로를 따름 · 수정 허브 1개로 통합

**1차 신호**: "뒤로가기가 헷갈림. 뒤에 페이지가 더 있을 것 같은 느낌" / "분석에 네비게이션 바 보이게"

| | |
|---|---|
| 가설 | Back(직전 맥락)과 하단 Nav(주요 영역)의 역할이 분리되면 길을 잃지 않는다 |
| 과업 (위치 안 알려줌) | ① 이전 결과로 돌아가 보세요 ② 입력한 것 중 하나를 고쳐 보세요 ③ 홈으로 가 보세요 |
| 관찰할 행동 | 각 과업의 소요 시간 · 잘못 누른 횟수 · Back과 Nav 중 무엇을 먼저 쓰는가 |
| 성공 신호 | 3과업 모두 도움 없이 완료 · 수정 후 결과로 자연스럽게 복귀 |
| 실패 신호 | Back을 반복해서 누름 · 수정 경로를 못 찾음 · 홈에 가려고 Back을 여러 번 |

## H5. Premium 발견성

**변경한 것**: low-confidence 결과에도 Premium 진입을 붙였다(이전엔 없었다).

| | |
|---|---|
| 가설 | 과업을 주지 않아도 무료 결과를 읽다 보면 Premium을 스스로 만난다 |
| 관찰할 행동 | **과업 없이 관찰.** 스크롤 중 멈추는가 · 누르는가 · 몇 번째 화면에서 처음 보는가 |
| 질문 (다 본 뒤에만) | "더 볼 수 있는 게 있다는 걸 눈치채셨어요?" · "어디서 보셨어요?" |
| 성공 신호 | 진행자 안내 없이 발견 · 최소 한 번 누름 |
| 실패 신호 | 끝까지 못 봄 · 봤지만 광고로 인식하고 건너뜀 |

⚠️ "유료 버튼 보셨어요?"라고 먼저 묻지 않는다. 물으면 그 순간 데이터가 사라진다.

## H6. Premium 상품 이해 ★ 이번 UT 핵심

**변경한 것**: 렌즈 3화면이 각자 가격을 갖던 구조를 버리고, 세 화면 모두 **동일한 Bundle
카드**(가격 1개 + 포함 렌즈 3행, 렌즈 행에는 가격 없음)를 쓴다. unlock 후엔 가격이 사라진다.

**1차 신호**: "사주랑 별자리랑 묶어서 간다고 하면 결제를 할 수도 있을 것 같아"

| | |
|---|---|
| 가설 | 가격을 한 번만 보여주고 그 아래 포함 항목을 나열하면, 하나의 관계 리포트로 이해한다 |
| 관찰할 행동 | 렌즈 3화면을 오가며 가격을 몇 번 보는가 · "또 내야 해?" 류 발화 |
| 질문 | **"이 ₩1,900으로 무엇을 볼 수 있다고 이해하셨어요?"** (열린 질문 · 보기 제시 금지) |
| 성공 신호 | `사주 + MBTI + 별자리 + 관계 상세 분석`을 **하나**로 묶어 말한다 |
| 실패 신호 | `사주 1,900 / MBTI 1,900 / 별자리 1,900`으로 이해 · "렌즈마다 사야 하나요?" |

## H7. FREE vs Premium 차이

**1차 신호**: "무료만으로는 유료 결제까지 고려하진 않을 것 같음" / "내용으로 다 나온 것 같아"

| | |
|---|---|
| 가설 | Premium이 '더 긴 글'이 아니라 '따로 답한 것들의 연결'로 읽히면 차이가 인지된다 |
| 관찰할 행동 | Premium 리포트에서 어디를 오래 보는가 · 어디를 건너뛰는가 |
| 질문 | **"무료 결과와 Premium 결과의 가장 큰 차이는 뭐라고 느끼셨어요?"** (사용자 언어 그대로 기록) |
| 성공 신호 | '연결' · '왜 그런지' · '확인할 것' 류의 말이 나온다 |
| 실패 신호 | "더 길다" · "비슷한데 자세하다" · "차이를 모르겠다" |

## H8. WTP — 반드시 4개로 나눠서 묻는다

한 질문으로 합치면 "비싸요/싸요"만 남는다.

```
1. (가격 보기 전) 이 뒤에 뭐가 더 나올 거라고 생각하셨어요?
2. (Premium 본 뒤) 생각했던 거랑 실제가 어떻게 달랐어요?
3. 실제로 ₩1,900을 내실 것 같으세요?
4. 안 내신다면 가장 큰 이유가 뭔가요?
```

| | |
|---|---|
| 성공 신호 | 2번에서 "생각보다 구체적" · 3번 yes · 4번이 가격이 아닌 다른 이유 |
| 실패 신호 | 2번에서 "예상대로" · 4번이 "이 정도는 무료로도 알 수 있어서" |

참고: 1차에서 `4,200~4,500원`이 비교 기준으로 언급됐다(족발 값 비유). 가격 자체보다
**기대와 실제의 간격**을 본다.

## H9. Lovy / 컨셉 연속성

**1차 신호**: "캐릭터랑 티키타카 하는 것 같았는데 갑자기 사라지고 글자만 남았다" / "논문 같다"

| | |
|---|---|
| 가설 | 입력은 대화, 결과는 러비가 쓴 보고서 — 이 설정이 전달되면 단절로 느끼지 않는다 |
| 관찰할 행동 | 결과 화면에서 표정·속도 변화 · "어?" 하는 지점 |
| 질문 | **"처음 질문할 때와 결과를 볼 때, 같은 서비스라는 느낌이 이어졌나요?"** |
| 성공 신호 | "러비가 정리해준 느낌" · 단절 언급 없음 |
| 실패 신호 | "갑자기 딱딱해졌다" · "다른 앱 같다" |

⚠️ **"러비가 더 있으면 좋겠어요?"라고 먼저 묻지 않는다.** 물으면 전원이 yes라고 답한다.

## H10. Value Density

**1차 신호**: "텍스트가 너무 많아서 잘 안 읽힘" / "같은 말이 반복" / "정보 피로도가 높아짐"

| | |
|---|---|
| 가설 | 분량이 아니라 '읽은 양 대비 새로 얻는 것'이 문제다 |
| 관찰할 행동 | **어디서 읽기를 멈추는가** · 어디를 펼치지 않는가 · 어디를 빠르게 스크롤하는가 (화면 녹화 권장) |
| 질문 | (멈춘 지점을 짚으며) "이 부분에서 더 볼 필요 없다고 느끼신 이유가 뭐였어요?" |
| 성공 신호 | 끝까지 읽음 · 멈춘 이유가 '충분히 알았다' |
| 실패 신호 | 중간에 스크롤 가속 · "아까 본 것 같은데" |

⚠️ "글이 많았나요?"로 묻지 않는다. 물으면 전원이 yes라고 답한다.
기록해둔 POLISH-01(힌트 라벨 중복)이 실제로 걸리는지도 여기서 본다.

## H11. Share 발견성

**1차 신호**: "친구랑도 써보고 싶음" — 공유 버튼은 있었지만 못 찾았다

| | |
|---|---|
| 가설 | 결과를 다 읽은 자리에 공유 진입이 있으면 스스로 찾는다 |
| 관찰할 행동 | "친구랑 해보고 싶다"는 말이 나왔을 때 **먼저 설명하지 않고** 무엇을 하는지 본다 |
| 질문 | (한참 뒤) "친구한테 보여주고 싶으면 어떻게 하실 것 같아요?" |
| 성공 신호 | 스스로 공유 CTA를 찾는다 |
| 실패 신호 | 링크를 직접 복사하려 함 · 스크린샷을 찍으려 함 |

⚠️ 현재 공유는 **카드 이미지·요약 문구**다. `상대가 URL로 답하면 내 결과에 합쳐진다`는
기능은 없다 — 참가자가 그렇게 기대하는지도 함께 기록한다.

## H12. Retention trigger

**1차 신호**: "새로운 사람이 생기면" / "오래된 연인에게 변화구" / "일회성이면 번거로움"

| | |
|---|---|
| 가설 | 재방문 동기는 '새 사람'만이 아니라 '관계 변화 시점'이다 |
| 질문 | **"다시 쓴다면 언제일 것 같으세요?"** (후보를 먼저 보여주지 않는다) |
| follow-up (답한 뒤에만) | 새 사람 · 갈등 · 오래된 관계 · 관계 변화 중 어디에 가까운지 |
| 성공 신호 | 구체적 시점을 스스로 말한다 |
| 실패 신호 | "글쎄요" · "한 번 보면 됐어요" |
