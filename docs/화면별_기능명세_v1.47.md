## 읽는 법

각 화면을 같은 표로 적는다.

| 칸 | 뜻 |
|---|---|
| **목적** | 이 화면이 사용자에게 해결해 주는 한 가지 |
| **진입** | 어디서 오는가 |
| **다음** | 어디로 나가는가 (버튼 · 리다이렉트) |
| **구성** | 렌더 순서. 조건부는 `(조건)`으로 표시 |
| **입력·검증** | 사용자가 넣는 값과 막는 규칙 |
| **분기** | 빈 상태 · 부분 입력 · 실패 등 다른 화면이 되는 조건 |
| **저장** | `SessionAnswers`의 어느 키를 바꾸는가 |
| **Analytics** | 실제로 발생하는 이벤트 이름 |
| **원칙** | 이 화면에서 **하지 않기로** 한 것 (가장 중요한 칸) |

기호: ⭐ 핵심 결과 화면 · ⚠️ 회귀 주의 · (선택) 건너뛸 수 있는 입력

## 0. 전역 사양 (모든 화면 공통)

### 0.1 셸

| 항목 | 값 |
|---|---|
| 프레임 | `ScreenLayout` — `max-w-[430px]` 고정 폭. 데스크톱에서도 폰 프레임 |
| 기준 뷰포트 | **393×852** (모든 실측 · QA 기준) |
| 헤더 | `ScreenHeader` — 뒤로가기 + 우측 `action` 슬롯(Tag · 배지) |
| 하단 | 결과 화면은 `BottomNavigation` 4탭, 입력 화면은 단일 CTA |
| 하이드레이션 | `HydrationGate` — localStorage 복원 전에는 라우트 판정을 하지 않는다 |
| 캐릭터 | 러비(Lovy) — `LovyMessage`(말풍선) · `LovyNote`(메모) · `Lovy`(단독). 도배 금지 |
| 뒤로가기 | `useContextualBack` — 온 곳으로 돌아간다(고정 목적지가 아님) |
| 스크롤 | `useScrollRestore` · `useAnchorScroll` — 결과 화면은 위치를 복원한다 |

### 0.2 저장소

| 저장소 | 키 | 내용 |
|---|---|---|
| localStorage | `lym.session.v1` | `SessionAnswers` 전체 (업로드 사진 objectURL 제외) |
| localStorage | `lym.history.v1` | 관찰 기록(History Entry) |
| localStorage | `lym.analytics.v1` · `lym.consent.v1` | 이벤트 큐 · 분석 동의 |
| localStorage | `lym.premium-intent.v1` · `lym.premium.variant` | 지불 의향 · 가격 variant |
| **sessionStorage** | `lym.premium-preview-unlock.v1` | Preview Unlock — **탭 한정. 결제 기록이 아니다** |

복원 규칙 — 값이 유효하지 않으면 **추정하지 않고 미입력(null)으로 강등**한다(`sessionSanitize`).
저장 실패(Quota)는 흐름을 막지 않되 상태로 알린다. **자동으로 기록을 지우지 않는다.**

### 0.3 데이터 위계 (모든 화면에서 동일)

```text
CORE           실제 관계 신호 — 동기화율 · Mirror · 관찰 기록을 만드는 유일한 근거
SUPPORTING     MBTI — 참고 렌즈. 점수에 넣지 않는다
ENTERTAINMENT  사주 · 별자리 — 점수 · Mirror · 기록 어디에도 넣지 않는다
```

### 0.4 공통 금지

```text
❌ 없는 결과를 본 것처럼 말하기          ❌ '천생연분 / 상극 / 성공률 / 궁합 %'
❌ 상대의 마음 · 성격을 단정             ❌ 참가자 화면의 개발 메타 문구(DEMO · 엔진 미연결 등)
❌ 사진을 퍼널 입장권으로 쓰기           ❌ 자동 삭제 · 자동 보정 · 소급 추정
```

# 4. Lens (Add-on)

> **Lens 계약 (LENS_INFORMATION_HIERARCHY 260916 · freeze)**
>
> ```text
> Lens = 별도 분석 서비스가 아니다.
> Lens = 같은 관계를 다른 해석 프레임으로 한번 더 보는 것.

# 부록 C. 화면 공통 검증 규칙

| 규칙 | 적용 |
|---|---|
| 필수 미입력 CTA | `InlineError`로 **그 자리에서** 알린다. 화면 이동 금지 |
| '모름'(`x`) | 정상 값으로 취급. 점수 계산에서 **제외**하고 알고 있는 항목 수(`known/4`)만 센다 |
| 자유서술 | 300자 제한. 원문은 결과 · 공유 · 기록 어디에도 그대로 남기지 않는다 |
| 복원 실패 값 | 추정하지 않고 미입력(null)으로 강등 |
| 생년월일 | 존재하지 않는 날짜 · 미래 · 과도한 과거를 각각 구분해 오류 표시 |
| 하이드레이션 | `HydrationGate` 통과 전에는 라우트 가드가 판정하지 않는다 |

# 부록 D. 이 문서를 고칠 때

1. **코드가 정본이다.** 화면을 바꿨으면 이 문서의 해당 표를 같은 커밋에서 고친다.
2. 계산식 · AI 프롬프트 · 점수 로직은 여기 적지 않는다 → `docs/기능명세_현행.md` 7~9장.
3. '원칙' 칸은 지우지 않는다 — **하지 않기로 한 것**이 이 제품의 정의다.
4. 화면을 추가하면 부록 A 인덱스와 부록 B 이벤트 색인에도 같이 넣는다.
